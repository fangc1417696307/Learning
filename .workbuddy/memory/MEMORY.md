# 项目长期记忆

## 项目性质
- 软件工程课程项目：个性化资源生成与学习多智能体系统（Python + FastAPI + SQLite，后续 Vue）。
- **这是学习项目，不是交付项目**：讲原理、给方向、做 review，不直接代写实现；每个模块先让用户写设计草稿。
- 始终用中文；每节课写成 `docs/lessons/NN-课程名.md`，末尾保留「我的理解」。

## 约定与事实
- 端口固定 **8001**（本机 8000 被 C-Lodop 占用），启动：`uvicorn main:app --reload --port 8001`。
- 后端分层：`main.py` / `routers/` / `schemas.py` / `db.py` / `deps.py`。
- 当前进度：第 1～10 课完成；`config.py` / `.env` 尚未创建（第 12 课未做）。
- 库里现有 `students(id,name,major,age,goal)` 是第 5～7 课练习表，不是正式建模。

## 契约基准（2026-10-25 起）
- `docs/文档/数据库设计说明书.docx`：14 张表、七维字典、DDL，是持久层的唯一依据。
- `docs/文档/接口规范文档.docx`：22 个接口、统一响应体 `{code,message,data,request_id}`，是前后端与多智能体并行开发的契约。
- 统一命名：表名单数 snake_case；主键统一 `id`；外键 `<表名>_id`；时间 `_at` 且按 UTC 存 ISO8601。

## 文档集（四份，2026-10-27 起齐全）
文件统一 `7组-` 前缀，放在 `docs/文档/`；机器可读契约在 `docs/api/openapi.yaml`。
1. `7组-需求分析.docx`（SRS，25 页）——六章：引言/功能描述/功能需求/外部接口/需求建模/数据字典。
   - 7 个功能 F-00～F-06，10 个用例 UC-01～UC-10，每条用例含主流程 + 异常流 + 验收标准。
   - 优先级 P0（需求 1/2/3）/P1（推送、辅导）/P2（评估）；表 3-12 是需求→用例→接口→表 的追溯矩阵。

3. `7组-接口规范文档.docx`（32 页，22 个接口，汇总表路径已做内部超链接）
4. `docs/api/openapi.yaml`（23 路径 / 24 操作 / 53 schema）

## 踩过的坑
- **WPS 另存会丢失 `<w:hyperlink w:anchor>` 内部链接**（书签保留）。加完链接后不要再用 WPS 另存。
- Prism 5.x 在 allOf 分支里遇到 `$ref` 会把 data 生成为 null；响应体用扁平结构。
- python-docx 生成的 docx 比 Word 小 ~25%，是命名空间去重，不是内容丢失（可用段落/表格/字符数比对确认）。
